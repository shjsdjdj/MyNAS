# Internationalization

MyNAS uses a deliberately small translation layer:

```text
src/locales/
├── zh.ts
├── en.ts
└── index.js
```

`t(key, variables)` resolves nested dictionary keys and replaces simple `{variable}` placeholders. `setLocale()` updates the reactive locale, the document language, and `localStorage`.

The Settings API also stores the language preference in SQLite so the user's choice follows their account. Login, menus, Dashboard, upload, photos, timeline, recent uploads, file browser, Trash, Settings, errors, toast messages, and dialogs all use the shared dictionary.

No external i18n framework is required. Add a new key to both dictionaries and call `t('section.key')` from Vue.
